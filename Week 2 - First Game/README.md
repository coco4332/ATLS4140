
First Godot Game

Credits
Tutorial

This project was built by following this Godot tutorial on YouTube.
https://www.youtube.com/watch?v=GwCiGixlqiU&t=1201s

Time to complete the tutorial: ~2.5 hours

Assets
Character and enemy sprites (soldier player, orc enemy) from the Tiny RPG Character Asset Pack by Zerie.
https://zerie.itch.io/tiny-rpg-character-asset-pack

Changes I Made

After finishing the tutorial, I made three changes to make the game my own.

1. Swapped the player to the soldier sprite

Replaced the tutorial's default player model with the soldier sprite from the Tiny RPG pack and set up all of its directional walk and attack animations.

Time: ~1 hour

2. Swapped the enemy to the orc sprite

Replaced the tutorial's mob with the orc sprite and implemented its animations, including walk, hurt, and a death animation that plays fully before the enemy is removed from the scene.

Time: ~1 hour

3. Reworked the player attack from a gun to a bow

Changed the player's attack from firing a gun to drawing a bow, with a new bow animation and an arrow projectile in place of the original bullet.

Time: 20-30 minutes
